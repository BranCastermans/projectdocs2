Week 8 — Tailwind CSS

```

Afgelopen week heb ik gewerkt aan een HTML-pagina voor mijn projectdocumentatie en tegelijk Tailwind CSS geïnstalleerd via npm. Na de installatie heb ik Tailwind geconfigureerd zodat het een eigen output.css kon genereren.

In de pagina zelf heb ik de gegenereerde Tailwind-stylesheet gekoppeld naast mijn bestaande CSS-bestanden. Vervolgens kon ik beginnen experimenteren met utility-classes om de structuur en vormgeving van de site te verbeteren.

De combinatie van mijn eigen CSS en Tailwind zorgde ervoor dat ik sneller kon stylen en overzichtelijker kon werken.
```
